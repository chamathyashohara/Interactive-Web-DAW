# Interactive Learning and Collaborative Web-Based Digital Audio Workstation

A research project developing an interactive, beginner-friendly and collaborative web-based Digital Audio Workstation for modern music production.

## Project Structure

- `client` - Frontend application
- `server` - Backend application
- `docs` - Project documentation

## Technology Stack

- React + Vite + TypeScript
- Tailwind CSS
- Node.js + Express
- MongoDB + Mongoose
- Socket.IO
- WebRTC
- Tone.js
- WaveSurfer.js
